# Дизайн-система по трём референсам

Разбор приёмов, которые сделали эти сайты такими, какие они есть, — чтобы собирать новые сайты в похожем стиле.
Три направления:

1. **Arctic Tech-Wear** (магазин пуховиков, ледяной сине-серый)
2. **Dark Editorial Collage** (тёмное портфолио с оранжевым акцентом, манга/постеры)
3. **Warm Luxury Serif** (AI-агентство: кремовый + шоколадный, курсивная антиква)

В конце: общие принципы, которые работают во всех трёх, и готовые промпты для генерации.

---

## 0. Что объединяет все три сайта

| Приём | Как проявляется |
|---|---|
| **Ограниченная палитра** | 1 базовый тон + 1 акцент. Никакой радуги. Цвет «держит» фотография, а не UI. |
| **Огромный контраст размеров шрифта** | Заголовок 64–120px рядом с подписями 9–11px. Середины почти нет. |
| **Фото — главный герой** | UI минимален: тонкие линии, мелкий текст, кнопки-контуры. Всё работает на картинку. |
| **Цельная обработка изображений** | Все фото в одном цветокоре (холодный синий / ч-б + оранжевый / тёплый бордо). Это 50% стиля. |
| **Много воздуха** | Секции 120–200px по вертикали. Блоки не «набиты». |
| **Мелкий служебный текст как декор** | Артикулы, коды, «[ NEW COLLECTION ]», «01 —— 07», даты, звёздочки ✦. Создаёт ощущение продуманности. |
| **Один «нарушающий» элемент** | Граффити поверх фото / коллаж с наложением / большая дуга. Без него стиль скучный. |

## 1. Arctic Tech-Wear

**Настроение:** холод, высота, техничность, стритвир + альпинизм. «Снаряжение из будущего».

### 1.1 Палитра

Монохром в одном оттенке — холодный сине-серый (hue ≈ 210°). Все цвета — один тон разной светлоты, без чистого белого и чёрного.

| Токен | HEX | Роль |
|---|---|---|
| `--ice-900` | `#1E2C3A` | самый тёмный, тени, тёмные изделия |
| `--ice-800` | `#2E4357` | фон hero / футера |
| `--ice-700` | `#3F5873` | основной фон страницы |
| `--ice-600` | `#557089` | фон секций, подложка каталога |
| `--ice-400` | `#8FA8BF` | второстепенный текст, линии |
| `--ice-300` | `#AEC3D6` | фон карточек товара |
| `--ice-100` | `#DCE6EF` | светлые плашки |
| `--snow` | `#F4F7FA` | заголовки, основной текст |

Акцента как такового нет — «акцент» = светлота (белый текст на сине-сером). Цветные точки вариантов (white / blue / black) — единственные вкрапления.

### 1.2 Типографика

| Роль | Шрифт (Google Fonts) | Параметры |
|---|---|---|
| Display | **Oswald** / Bebas Neue / Archivo Narrow 700 | UPPERCASE, 64–110px, line-height 0.9, tracking -0.01em |
| Служебный / лейблы | **Space Mono** / JetBrains Mono / IBM Plex Mono | 9–11px, UPPERCASE, tracking 0.1–0.15em, opacity 0.7 |
| Текст | Inter / Manrope | 13–14px, редко |
| Цена | Mono | `$899.99` — моноширинный, как в спецификации |

Знак ™ после названий: `ARTIC 01™`, `AURORA™` — мелкий трюк, который делает продукт «серией».

### 1.3 Ключевые приёмы

1. **Граффити-тег спреем поверх фото.** Огромная надпись-тег (полупрозрачная, белая, с «распылённым» краем) за моделью или поверх горы. Соединяет «улицу» и «горы».
   - Делается PNG/SVG тегом + `mix-blend-mode: screen` или `opacity: .5`, + `filter: blur(1px)` для спрея. В секции-манифесте — сильный blur/шум (`filter: url(#noise)`).
2. **Слои глубины.** Фон-гора → тег → модель → UI. Модель «перекрывает» тег — тег всегда позади головы.
3. **Скошенные углы карточек (chamfer).** Карточки товара без скругления, но с одним срезанным углом:
   ```css
   clip-path: polygon(0 0, calc(100% - 14px) 0, 100% 14px, 100% 100%, 0 100%);
   ```
4. **Восьмиугольная кнопка «Add to cart».** Контурный октагон со стрелкой ↗ — вместо банальной прямоугольной кнопки.
5. **Служебный текст в квадратных скобках:** `[ NEW COLLECTION ]`, `[ PROTOCOL: ALTITUDE OPS_01 ]`. Mono, мелко, 2–3 строки столбиком рядом с заголовком.
6. **Каталог как lookbook:** модели в полный рост на однотонном светлом фоне (`--ice-300`), одинаковая поза, центр. Под карточкой: название UPPERCASE mono → описание → точки цветов → цена.
7. **Счётчик слайдера** `01 ———— 07` — две цифры и тонкая линия.
8. **Финальный манифест** — гора на весь экран + огромный 3-строчный слоган снизу слева (`BUILT FOR COLD / MADE FOR HEIGHT / FORGED TO LAST`) + маленький текст-кредо сбоку + штрихкод как декор.
9. **Сайт «вложен» в фон:** весь контейнер (max-width ~1200) лежит поверх полноэкранной фотографии гор, которая видна по бокам.

### 1.4 Компоненты

- **Nav:** логотип-монограмма слева, ссылки mono 10px в скобках по центру, иконки (поиск, корзина) в маленьких квадратах справа.
- **Кнопка-фильтр:** белый контур, radius 4–6px, mono 10px.
- **Селектор размеров:** просто буквы `S M L XL` mono, активная подчёркнута.
- **Цветовые точки:** 8px круги + подпись mono.
- **Соцсети:** маленькие белые квадраты 16px с иконкой.

### 1.5 Фото

Студийные 3D/AI-рендеры, холодный свет, модель в маске/очках (анонимность → «снаряжение»), фон однотонный или горы в дымке. Цветокор: десатурация + сдвиг в синий.

## 2. Dark Editorial Collage

**Настроение:** андерграунд, манга, постеры, японская типографика, «zine». Галерея арта.

### 2.1 Палитра

| Токен | HEX | Роль |
|---|---|---|
| `--bg` | `#141414` | фон (не чистый чёрный!) |
| `--bg-2` | `#1C1C1C` | футер, подложки |
| `--line` | `#262626` | вертикальные линии сетки |
| `--text` | `#FFFFFF` | заголовки |
| `--muted` | `#8C8C8C` | текст абзацев |
| `--paper` | `#E9E9E9` | светлые картинки/постеры |
| `--accent` | `#F26A1B` | оранжевый — единственный цвет |

Правило: **оранжевый только в изображениях и 1–2 точках UI** (активный пункт меню, рамка стрелок, линия футера). Кнопки — НЕ оранжевые.

### 2.2 Типографика

| Роль | Шрифт | Параметры |
|---|---|---|
| Display | **Rajdhani 700** / Teko / Saira Condensed / Oswald | UPPERCASE, 28–40px, line-height 1.05, 2 строки |
| Текст | Barlow / Roboto / Inter | 12–13px, серый, line-height 1.7, узкая колонка 300–340px |
| Nav / кнопки | тот же display | 10–11px, bold, UPPERCASE, tracking 0.08em |
| Логотип | Брашевый/граффити шрифт | единственный «рукописный» элемент |

Под заголовком — **короткая белая черта** 40×2px.

### 2.3 Ключевые приёмы

1. **Зигзаг (шахматка):** блок «картинки слева — текст справа», следующий — наоборот. 4–5 таких проектов подряд.
2. **Коллаж из 2–3 изображений с наложением.** Одна большая работа + 1–2 маленькие, сдвинутые и перекрывающие её край (`position:absolute`, отрицательные отступы). Каждая картинка — разный «тип»: оранжевая, ч-б, белый постер.
3. **Двухцветная графика:** все изображения — чёрный + оранжевый или чёрный + белый (дуотон / трафарет / манга-штрих). Это главный узнаваемый приём.
4. **Видимая сетка:** тонкие вертикальные линии (`#262626`) по колонкам на всю высоту страницы:
   ```css
   background-image: repeating-linear-gradient(90deg, transparent 0 calc(25% - 1px), #262626 calc(25% - 1px) 25%);
   ```
5. **Японские/азиатские иероглифы как графика** — внутри картинок, на постерах; служебный текст «NAME / PLACE / DATE» на постерах.
6. **Квадратные кнопки-стрелки по краю экрана** (12px, оранжевая рамка) — навигация вверх/вниз.
7. **Футер по центру:** логотип, слоган разрядкой (`A THEME FOR A CREATIVE SOCIETY`, tracking 0.4em), ссылки в строку; сверху тонкая оранжевая линия.

### 2.4 Компоненты

- **Nav:** логотип слева, меню UPPERCASE 10px справа, активный пункт оранжевый, иконки корзины/поиска/бургера.
- **Кнопка:** контур 1px белый, прямоугольник без скругления, `padding: 10px 22px`, 10px bold uppercase. Hover — заливка белым, текст чёрный.
- **Радиусы:** 0 везде.

## 3. Warm Luxury Serif

**Настроение:** премиум, бьюти, мода, «журнал Vogue встречает SaaS». Тёплое, мягкое, дорогое.

### 3.1 Палитра

| Токен | HEX | Роль |
|---|---|---|
| `--cream` | `#F6EFE7` | светлый фон |
| `--card` | `#EBDFD1` | карточки на тёмном |
| `--chip` | `#E4D9CB` | бейджи |
| `--espresso` | `#140706` | тёмный фон (почти чёрный, но тёплый) |
| `--ink` | `#1B100D` | основной текст |
| `--muted` | `#6E605A` | второстепенный текст |
| `--wine` | `#6B1F1A` | акцент (вторая строка заголовка, звёздочки) |
| `--btn` | `#2B0F0C` | основная кнопка |

Правило: никаких холодных серых — **все нейтральные с примесью коричневого**.

### 3.2 Типографика

| Роль | Шрифт | Параметры |
|---|---|---|
| Display | **Instrument Serif** / Cormorant / Playfair Display / PP Editorial New | 48–64px, line-height 1.0, tracking -0.02em, часто *italic* |
| Огромные цифры | тот же serif italic | 72–96px (`10x`, `60%`, `100+`) |
| Текст / UI | **Inter** / Manrope / Geist | 13–15px, regular |

Приём: **две строки заголовка разного цвета** — первая `--ink`, вторая `--wine` (+ курсив). «Your content. Powered by AI. / *Perfected by humans*».

### 3.3 Ключевые приёмы

1. **Переход светлый → тёмный через огромную дугу.** Тёмная секция начинается не прямой линией, а гигантским эллипсом:
   ```css
   .dark { background: var(--espresso); border-radius: 50% 50% 0 0 / 120px 120px 0 0; }
   ```
   (или большой `div` с `border-radius: 50%` шириной 140vw).
2. **Горизонтальная лента вертикальных медиа** (формат 9:16 как Reels/TikTok), карточки radius 16–20px, выходят за края экрана, плюс иконка play по центру и счётчик просмотров `👁 2.2M` в углу.
3. **Бесконечная бегущая строка логотипов** (marquee), логотипы приглушённые (opacity .7, один цвет).
4. **Социальное доказательство у CTA:** кнопка + стопка аватаров (overlap −8px) + «Trusted by 100+ brands».
5. **Бейджи-секций** — маленький чип `✦ About us` над заголовком, radius 4px.
6. **Декоративные звёздочки ✦✦✦** — иногда как «рейтинг» (заполнены 1/3, 2/3, 3/3 в карточках статистики).
7. **Карточки-статистики:** светлые на тёмном фоне, radius 20px, текст сверху маленький, огромная цифра serif italic внизу слева. Карточки высокие (ratio ~1:1), много пустоты.
8. **Асимметричный заголовок секции:** большой serif слева (2 строки), маленький абзац справа, выровнены по низу.

### 3.4 Компоненты

- **Nav:** логотип (иконка-звезда + serif italic) слева, ссылки 12px по центру, кнопка-пилюля с контуром справа.
- **Кнопка primary:** пилюля (`radius: 999px`), заливка `--btn`, лёгкий градиент сверху вниз, белый текст 13px.
- **Кнопка secondary:** пилюля с контуром 1px `--ink`.
- **Радиусы:** 999 кнопки, 16–20 карточки, 4 бейджи.

## 4. Шпаргалка: как выбрать и смешивать

| Параметр | Arctic | Dark Collage | Warm Serif |
|---|---|---|---|
| Фон | сине-серый mid-tone | #141414 | крем ↔ эспрессо |
| Акцент | светлота | оранжевый | винный |
| Заголовки | condensed sans UPPER | condensed sans UPPER | serif + italic |
| Мелкий текст | mono в [скобках] | sans серый | sans |
| Радиусы | 0 + срезанный угол | 0 | 999 / 20 |
| Кнопки | контур / октагон | контур прямоугольник | пилюли |
| Фирменный трюк | граффити-тег на фото | коллаж с наложением | дуга-переход + serif italic цифры |
| Подходит для | одежда, техника, спорт, игры | портфолио, музыка, арт, тату | агентства, бьюти, мода, SaaS-премиум |

**Не смешивать** скругления и шрифты из разных направлений — каждый стиль держится на своей «грамматике».

## 5. Анимации (подходят ко всем)

- Появление при скролле: `opacity 0→1` + `translateY(24px→0)`, 600–800ms, `cubic-bezier(.2,.7,.2,1)`, задержка 60–80ms между элементами.
- Заголовки: построчное появление (каждая строка из-под маски `overflow:hidden`).
- Картинки: лёгкий параллакс (слои двигаются с разной скоростью) — особенно в Arctic (гора/тег/модель) и в коллажах Dark.
- Hover карточек: `scale(1.02)` фото внутри, рамка не двигается.
- Marquee логотипов: 30–40s linear infinite, пауза на hover.
- Всегда уважать `prefers-reduced-motion`.

## 6. Чек-лист «чтобы было похоже, а не просто тёмный сайт»

- [ ] Все фото в одном цветокоре
- [ ] Палитра ≤ 2 цветов + нейтральные одного оттенка
- [ ] Заголовок минимум в 6 раз больше основного текста
- [ ] Есть мелкий «служебный» текст-декор
- [ ] Есть один фирменный «ломающий» приём (тег / коллаж / дуга)
- [ ] Секции разделены воздухом, а не линиями и тенями
- [ ] Тени почти не используются (стиль плоский)
- [ ] Одна форма кнопки на весь сайт

## 7. Готовые промпты для AI (Claude / v0 / Lovable)

**Arctic:**
> Сделай лендинг магазина технологичной верхней одежды. Палитра — монохром холодного сине-серого (#2E4357, #3F5873, #557089, #AEC3D6, #F4F7FA), без чистого чёрного и белого. Заголовки Oswald 700 uppercase 90px line-height .9, служебные подписи Space Mono 10px uppercase в квадратных скобках. Hero: модель в пуховике на фоне гор, за ней огромный полупрозрачный граффити-тег со спрей-эффектом. Карточки товаров на светлом фоне #AEC3D6 со срезанным правым верхним углом (clip-path), модели в полный рост. Кнопка add to cart — контурный восьмиугольник со стрелкой. Финальная секция — гора на весь экран и слоган из трёх строк.

**Dark Collage:**
> Сделай тёмное портфолио: фон #141414, тонкие вертикальные линии сетки #262626, единственный акцент — оранжевый #F26A1B (только в изображениях и активном пункте меню). Секции-проекты зигзагом: коллаж из 2–3 перекрывающихся изображений (оранжевый дуотон, ч-б манга-графика, белый постер) и текстовый блок — заголовок Rajdhani 700 uppercase 36px в 2 строки, белая черта 40px, серый абзац Barlow 13px, контурная прямоугольная кнопка VIEW PROJECT. Радиусы 0.

**Warm Serif:**
> Сделай лендинг креативного агентства. Светлый фон #F6EFE7, тёмный #140706, акцент винный #6B1F1A. Заголовки Instrument Serif 60px, вторая строка курсивом и винным цветом. UI — Inter. Кнопки-пилюли тёмные. Под hero — тёмная секция, начинающаяся огромной дугой, с горизонтальной лентой вертикальных видео-карточек (radius 18, play-кнопка, счётчик просмотров), бегущая строка логотипов, затем 3 карточки-статистики #EBDFD1 с огромными цифрами serif italic (10x, 60%, 100+) и звёздочками ✦.
