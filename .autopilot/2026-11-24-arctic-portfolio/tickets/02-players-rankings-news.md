# 02 — Игроки, профили, рейтинги и новости

**Требования:** G02, G03, G04, G05, G07, G08, G09, R04, R11i
**Зависит от:** 01
**Зона:** `players.html` · `player.html` · `rankings.html` · `news.html` · `js/pages/players.js` · `js/pages/player.js` · `js/pages/rankings.js` · `js/pages/news.js`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Геймер ищет игрока по нику, открывает его профиль со статистикой по каждой игре, смотрит рейтинг по Dota 2, CS2, Valorant или Apex и сортирует его по любому столбцу, читает ленту новостей с фильтром по игре. Всё в том же стиле Arctic и на тех же общих компонентах из таска 01.

## Из брифа, дословно

> «сделай сайи дляплатформы гейремров профили статистика рейтинги новости»
> «сделаешь для игр дота кс и ещее какие нибудь»

## Разделы спецификации

Истории 3–7, 9–13, 15, 18, 19; `interfaces.md` — функции `GP` и `GPUI` использовать, не переписывать.

## Критерии приёмки

- [ ] `players.html`: карточки игроков (аватар, ник, страна, основная игра); поиск по нику без учёта регистра на лету; фильтр «Все» и четыре игры; пустой результат — «Никого не нашли по запросу „…“» с кнопкой сброса
- [ ] `player.html?id=<id>`: ник, аватар, страна, основная игра, дата регистрации, место в общем рейтинге; статистика по каждой игре игрока (матчи, победы, винрейт, K/D или KDA для Dota 2, часы, очки) с переключением между играми
- [ ] `player.html` без `id` или с несуществующим `id` показывает «Игрок не найден» и ссылку на список игроков; в консоли нет ошибок
- [ ] `rankings.html`: таблица «место · игрок · очки · винрейт · K/D · матчи» по выбранной игре, по умолчанию Dota 2; щелчок по заголовку сортирует, повторный меняет направление; `?game=&sort=&dir=` читается при загрузке и обновляется при смене
- [ ] `news.html`: лента — дата, игра, заголовок, текст, новые сверху; фильтр по игре; по игре без новостей — «Новостей по этой игре пока нет»
- [ ] Все четыре страницы на 375 px без горизонтальной прокрутки (таблица рейтинга на телефоне читается), управляются с клавиатуры, с видимым фокусом
