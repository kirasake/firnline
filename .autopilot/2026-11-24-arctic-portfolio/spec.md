# Спецификация: платформа для геймеров в стиле Arctic

## Задача
Хочу сайт для платформы геймеров, на котором есть профили игроков, их статистика, рейтинги и новости по играм: Dota 2, CS2 и ещё нескольким. Оформление — моё направление Arctic Tech-Wear. Это просто сайт, который можно выложить на GitHub, без сервера.

Аудитория — геймеры, игроки платформы. Прежняя «смешанная» аудитория относилась к портфолио и снята вместе с ним.

## Решение
Статический сайт из пяти разделов: главная, игроки, профиль игрока, рейтинги и новости. Он открывается двойным щелчком по `index.html` и без доработки публикуется на GitHub Pages. Игроки, цифры и новости демонстрационные и везде явно помечены как демо. Их можно заменить настоящими, отредактировав файлы данных, а вёрстку трогать не нужно. Внешний вид: холодный сине-серый монохром, Oswald и Space Mono, служебные подписи в квадратных скобках, срезанные углы карточек, граффити-тег поверх горного фона.

Игры: **Dota 2**, **CS2**, **Valorant**, **Apex Legends**. Две последние выбраны за пользователя («и ещее какие нибудь»). Названия игр даются только текстом: логотипов, артов и фирменных цветов игр на сайте нет.

## Решения по реализации
- **Стек:** HTML, CSS и ванильный JS без сборки. Причина: «на гитхабе чисто сайт», GitHub Pages отдаёт файлы как есть.
- **Данные:** `data/*.js` — обычные скрипты, которые кладут данные в `window.GP_DATA`. JSON через `fetch` не подходит: он не работает с `file://`.
- **Логика:** чистые функции в `js/core.js` (UMD), тесты — `node --test` без зависимостей.
- **Шрифты:** Google Fonts — Oswald, Space Mono, Inter; без сети остаются системные запасные.
- **Картинки:** граффити-тег, аватары, штрихкод и запасные горы — inline SVG и CSS. Фото hero, манифеста и обложки игр сгенерированы через Higgsfield (G10, история 23) и лежат в `assets/img/`.
- **Объём демо:** 24 игрока, у каждого 1–4 игры; 12 новостей.
- **Публикация** на GitHub — необратимое внешнее действие, только по отдельному согласию пользователя. Сборка готовит репозиторий к публикации, но не публикует.
- **PRODUCT.md** переписывается под новую задачу: портфолио снято пользователем.

## Вне рамок
| Требование | Почему не сейчас |
|---|---|
| регистрация, вход, редактирование своего профиля | «чисто сайт» без сервера; бэкенд можно подключить позже |

## Открытые места
- Название платформы не дано: заглушка `[НАЗВАНИЕ]` в логотипе и заголовках, задаётся одной константой в `data/site.js`.
- Тексты новостей — `[НОВОСТЬ — впиши]`.
- Игроки и статистика — демо, помечены `[ DEMO DATA ]`.
